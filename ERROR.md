# Known Errors and Diagnostics

| Error Code / Symptom | Root Cause | Resolution / Mitigation |
|----------------------|------------|-------------------------|
| **False Sharing Latency Spikes** | The `write_index` and `read_index` of the atomic SPSC ring buffer are residing on the same CPU cache line. | Ensure strict `alignas(64)` and 60-byte `char` padding between atomic variables in the C++ struct. |
| **DPDK `rte_eal_init` Failure** | Insufficient contiguous memory or lack of root privileges. | Run with `sudo` and verify hugepages: `sudo sysctl -w vm.nr_hugepages=1024`. |
| **Python Segfault on Memoryview** | Python attempted to read a shared memory block that was deallocated or not correctly initialized by C++. | Ensure C++ `shm_open` and `ftruncate` complete *before* the Python script calls `SharedMemory(name=...)`. |
| **Torn Reads in NLP Sentiment** | The DRL agent read the sentiment vector while the NLP thread was partially updating it. | Verify the Seqlock implementation. The DRL agent MUST check that the sequence counter is even before reading, and unchanged after reading. |
| **Observer Effect (Slow Ticks)** | The React Dashboard WebSockets are fighting for CPU cycles with the DPDK polling thread. | Isolate the Redis/WebSocket server to CPU cores completely distinct from the C++ `isolcpus` execution group. |
| **C++ Socket SIGPIPE Crash** | A `send()` call on an unconnected or closed `PosixSocketClient` triggers a `SIGPIPE` signal, killing the test process. | Check for `sockfd >= 0` and pass `MSG_NOSIGNAL` flag (or `SO_NOSIGPIPE`) to the `send()` function call. |
| **Maven Fatal Error: release version 22 not supported** | The `pom.xml` demands Java 22 (`<java.version>22</java.version>`), but the WSL environment only has OpenJDK 21 installed. | Downgrade the `<java.version>` property to `21` in `pom.xml`. FFM is available as a preview in Java 21. |
| **JUnit UnsupportedClassVersionError (Preview Features)** | Java tests crash with "Preview features are not enabled" because `maven-compiler-plugin` enabled preview compilation, but the test runner didn't enable preview execution. | Add `<argLine>--enable-preview</argLine>` to `maven-surefire-plugin` configuration in `pom.xml`. |
| **JUnit UnsupportedClassVersionError (Preview Features)** | Java tests crash with "Preview features are not enabled" because `maven-compiler-plugin` enabled preview compilation, but the test runner didn't enable preview execution. | Add `<argLine>--enable-preview</argLine>` to `maven-surefire-plugin` configuration in `pom.xml`. |
| **JUnit UnsupportedClassVersionError (Preview Features)** | Java tests crash with "Preview features are not enabled" because `maven-compiler-plugin` enabled preview compilation, but the test runner didn't enable preview execution. | Add `<argLine>--enable-preview</argLine>` to `maven-surefire-plugin` configuration in `pom.xml`. |
| **Java DJL ModelNotFoundException at Runtime** | The Spring Boot app fails to boot if the ONNX model file does not exist on disk, throwing an exception from `@PostConstruct`. | Wrap the `loadModel()` call in a try-catch block and return dummy predictions if the `predictor` is null. |
| **Panama VarHandle WrongMethodTypeException** | `priceHandle.get(lobSegment, 0L, (long)level)` fails because `SequenceLayout.varHandle` only requires the segment and the index. The extra `0L` offset was incorrect. | Change the call to `priceHandle.get(lobSegment, (long)level)`. |
| **Spring Boot Maven Plugin UnsupportedClassVersion** | `mvn spring-boot:run` crashes with "Preview features are not enabled" because it forks a new JVM that ignores `MAVEN_OPTS`. | Pass `-Dspring-boot.run.jvmArguments="--enable-preview"` explicitly to the plugin. |
| **NPM EISDIR and UNC Path Errors in WSL** | Running `npm install` inside a WSL directory (`\\wsl.localhost\...`) from the Windows `npm.cmd` causes `lstat` and `EPERM` filesystem errors. | Install native Linux `nodejs` and `npm` within the WSL environment (`sudo apt install nodejs npm`), or move the dashboard folder to a native Windows drive. |
| **JMH ClassNotFoundException: ForkedMain** | `mvn exec:java` isolates classloaders in a way that prevents the forked JMH JVM from finding `ForkedMain` and the benchmark classes. | Change the JMH annotation from `@Fork(1)` to `@Fork(0)` so the benchmark runs inside the same JVM without attempting to fork. |
| **Python ModuleNotFoundError (gymnasium/onnxruntime)** | `pip install` fails silently on modern Ubuntu/WSL (PEP 668 "externally managed environment"), so dependencies are never installed. | Create a virtual environment (`python3 -m venv venv`), source it, and install the dependencies inside the isolated environment. |
